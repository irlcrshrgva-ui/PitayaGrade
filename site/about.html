About the capstone

Purpose-built for dragon fruit.

PitayaGrade explores how mobile computer vision can support more consistent fruit assessment while keeping human review central to important decisions.

Brand system

The dragon-and-fruit identity combines PitayaGrade’s magenta quality signal with the green tones of cultivation and growth.

View the repository

A clearer assessment workflow

Dragon-fruit images can vary because of lighting, background clutter, camera distance, maturity, and visible surface conditions. PitayaGrade provides a repeatable capture-and-review workflow that lets users inspect AI-assisted results instead of treating them as unquestionable answers.

What the application covers

  • Dragon-fruit detection and quality-grade estimation.
  • Maturity and visible-symptom assessment.
  • User-selectable model infrastructure.
  • Local records, analytics, reports, and notifications.
  • Photo mode, live-camera mode, and Android packaging.

Model choices

The project evaluates multiple quality-model families. Only checksum-verified runtime assets should become selectable in the released application.

Responsible use

PitayaGrade is a capstone research application. Quality and symptom outputs require inspection. Visible-symptom estimates are not laboratory diagnoses, and the testing APK is not yet a final signed production release.

Privacy approach

The current application keeps scan records in local browser or device storage. The public website does not upload a user’s dataset, camera photos, or private annotation files.
